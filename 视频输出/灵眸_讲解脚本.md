## 一句话主线

接上摄像头，用自然语言写规则，本地决策模型就能看懂画面并告警。

## 功能点出处（app.py）

| 讲解里的说法 | 代码依据 |
|---|---|
| 接 RTSP 视频流 / 本地文件 / 摄像头编号 | `Camera._open`：OpenCV + FFmpeg 拉流，TCP、低延迟参数 |
| 最近 2 秒取 3 帧一起送模型 | `config.frames=3`、`window=2.0`，`Camera.sample` 均匀取帧，`build_state` 告诉模型帧的时间顺序 |
| 本地决策模型 | Ollama `/v1/systemone`，模型 `clef-flash`，`keep_alive 30m` |
| 三种题型 | `to_question`：noul（是/否）、choice（多选一）、score（等级评分） |
| 给出概率 | `evaluate`：是/否返回概率，多选一返回各选项概率，评分返回分数 |
| 阈值 + 防抖 | `threshold`、`hold`：连续 hold 次命中才触发，连续 hold 次未命中才解除 |
| 告警级别 | `severity`：none 仅显示 / info 记录 / warn 黄色横幅 / danger 红色横幅 + 提示音 |
| 事件记录 + 截图 | `Analyzer._event`：保存触发帧 JPEG，最多 60 条 |
| 保存前测试 | `/api/test`：用当前画面试跑未保存的规则 |
| 多条规则一次请求 | `infer`：所有启用规则放进同一个 `questions` 字典，一次请求返回 |
| 每次判断约 5 秒 | 画面右上角实测 4.6–5.1 s（3 帧，3–5 条规则） |
